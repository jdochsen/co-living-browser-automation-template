# Co-Living Browser Automation Template

Version 1.0.0

1. Extract the ZIP.
2. Open chrome://extensions in Chrome and enable Developer mode.
3. Click Load unpacked and select the extracted folder containing manifest.json.
4. Open the extension and choose Settings.
5. Enable TurboTenant, PadSplit, or both. Edit the messages and click Save settings.
6. Reopen the extension on a supported lead or booking request.

Use {{firstName}}, {{fullName}}, and {{propertyAddress}} in messages. Add your own links and signature directly in each message. When both sources are enabled, TurboTenant lets you choose either saved message. PadSplit uses its own message.

Review the contact and message preview before preparing a Google Voice draft. Saved contacts and settings are stored locally in the Chrome profile. Export a contacts CSV for backup. The template is a separate unpacked extension and starts with its own settings and contacts.
